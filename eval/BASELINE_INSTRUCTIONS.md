# Participant instructions: basic folder and spreadsheet workflow

This is a controlled task using synthetic illustrations and supplied labels. Do not photograph anything or infer a real asset's condition. Use only the six supplied files and the exact labels on the task cards. The same cards and images are used in the other condition.

When the researcher starts the timer:

1. Copy each indicated PNG from the source folder into your empty output image folder. Keep its filename unchanged.
2. In the blank CSV template, enter one row per card. Enter the exact task ID (1–6), the copied filename, scenario, location, subject_id and condition. Both task ID and filename must be entered; they are not prefilled.
3. You may work in card order. Correct mistakes and check that each row points to its intended image. Do not rename, resize or edit images. Notes are optional and may remain blank.
4. Save the sheet as CSV (not XLSX). Check the saved file and tell the researcher when the complete output is ready. Corrections/recovery remain part of the timed task.
5. If you cannot finish or a tool fails, tell the researcher. Do not invent a successful save. Requests for help will be logged.

Fields:

| Column | What to enter |
|---|---|
| task_id | Exact card ID: 1, 2, 3, 4, 5 or 6; once each |
| file | Exact prepared PNG filename on the card |
| scenario | One of indoor, outdoor, vehicle, equipment, document, other; use the card's label |
| location | Exact location label printed on the card |
| subject_id | Exact asset label printed on the card; 2–4 capital letters, dash, 3–6 digits |
| condition | good, fair, poor or unknown; use the card's label |
| notes | Optional; at most 500 characters; can be left blank |

The basic template deliberately has no dropdown or required-field validation. You receive the same allowed values and task information as in the guided condition. The researcher handles file archiving and container naming after timing, without changing your answers.
