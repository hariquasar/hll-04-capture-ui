# Participant instructions: guided workflow

This is a controlled task using synthetic illustrations and supplied labels. Do not photograph anything or infer a real asset's condition. Use only the six supplied files and the exact labels on the task cards. The same cards and images are used in the other condition.

The researcher opens an empty session for your participant code and enables the six-task study mode before timing. When the researcher starts the timer:

1. Import the indicated PNG for each card from the source folder. Use file import, not the camera.
2. Enter the exact task ID and the card's scenario, location, subject_id and condition. Do not change image bytes. Notes are optional and may remain blank.
3. Save the record. Correct any error feedback and continue until the six task IDs have each been recorded once.
4. Review the records and correct mistakes using the available controls. Export the complete ZIP, check the downloaded file exists and opens, and tell the researcher the output is ready. Corrections and retry/export recovery remain part of timing.
5. If storage warns that data is only in memory, follow the available recovery/export controls before leaving. If you cannot finish or a tool fails, tell the researcher. Requests for help will be logged.

The researcher archives/renames the downloaded container after timing without changing your answers. Do not reset the session or discard a stored session unless the researcher has first preserved the output. Your task uses the same six files and labels as the basic workflow.
